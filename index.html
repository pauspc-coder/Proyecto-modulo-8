05 · CASO DE ESTUDIO

Alke Wallet: convertir requisitos en una experiencia funcional

Desafío

Construir una interfaz de billetera digital clara y responsive, incorporando operaciones de usuario y persistencia de información sin perder usabilidad.

Solución propuesta

Se estructuró la aplicación en pantallas y componentes funcionales, utilizando Bootstrap para la interfaz, JavaScript para la lógica y LocalStorage para conservar información entre sesiones.

Herramientas utilizadas

HTML5CSS3Bootstrap 5JavaScriptLocalStorageGit/GitHub

Aprendizajes

Fortalecí la organización del código, la semántica HTML, el diseño responsive, el manejo de eventos y la persistencia de datos en el navegador.

Impacto y evidencias

100%de las funcionalidades principales integradas en el flujo de la aplicación.
5+conceptos técnicos aplicados: UI, eventos, lógica, persistencia y responsive.
1producto digital documentado como evidencia de aprendizaje.
