## Publicación en GitHub Pages

1. Crear un repositorio público en GitHub, por ejemplo: `Proyecto-modulo-8`.
2. Subir `index.html`, la carpeta `css`, la carpeta `js` y `assets`.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar la rama `main` y carpeta `/ (root)`.
6. Guardar y esperar la publicación.
7. La URL tendrá un formato similar a:
   `https://github.com/pauspc-coder/Proyecto-modulo-8.git`
